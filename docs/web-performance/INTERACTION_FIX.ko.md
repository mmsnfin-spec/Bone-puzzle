# 오프닝 잘림·마우스 회전 조작 수정

검수일: 2026-10-25 (Asia/Seoul). 작업 브랜치: improvement/web-performance.

오프닝은 완성된 손을 보여주는 anatomy 시점을 낙하와 흩어짐에도 사용했다. 1920×1080 실제 브라우저에서 낙하 중 뼈의 투영 경계가 자막 영역과 화면 하단을 벗어나는 회귀 검사를 먼저 실패시켜 재현했다. 별도 intro 카메라 설정을 rendering 데이터 모듈에 추가하고, 캡션과 하단 자막·Skip 영역을 제외한 실제 Canvas 크기로 시점을 잡는다. 정답 좌표, 모델, 중력과 충돌 설정은 변경하지 않았다. 완료 화면의 anatomy 시점도 유지한다.

기존 Arcball 회전은 하단 ROTATE 전환 뒤에만 발견하기 쉬웠다. 뼈 선택 패널에 ‘마우스로 회전 / 마우스로 이동’과 현재 모드의 드래그 안내를 추가했다. 두 UI는 동일한 interactionMode와 기존 Quaternion 제어기를 사용한다. 선택한 뼈를 왼쪽 드래그하면 회전하며 Shift는 임시 이동이다. 배치 완료된 뼈의 조작 제한도 유지한다. 이전 공개 사이트에는 해당 작업 브랜치의 회전 기능이 아직 반영되지 않은 점은 코드 결함과 별도로 구분한다.

검증 결과:

- 단위/UI 60개 통과. 프로덕션 빌드 및 원본 27개 GLB·좌표 검사 통과.
- Linux headed Chromium 브라우저 13개 통과. 1920×1080, 1920×900의 조립·낙하·정렬·타이포그래피 구간에서 27개 전체 메시의 투영 경계를 반복 검사했다.
- 서로 다른 두 뼈를 실제 클릭하고 선택 패널의 회전 버튼을 사용해 실제 드래그했다. Quaternion 변화, 위치 유지, 다른 26개 뼈 불변, 카메라 불변을 검사했다.
- 기존 27개 포인터 조립, 스냅, 키보드, 저장/복원, 가이드, 취소, 포커스 중지, 모바일 검사도 통과했다.
- 이 수정의 Windows Chrome/Edge 결과는 GitHub 업로드 후 별도 확인이 필요하다. 기존 커밋의 성공 결과를 이번 수정 결과로 재사용하지 않는다.
- 이번 수정에서 CPU/Lighthouse를 재측정하지 않았다.
