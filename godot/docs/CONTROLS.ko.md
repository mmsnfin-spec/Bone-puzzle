# 조작 안내

## 시작과 메뉴

타이틀에는 `BONE PUZZLE`과 하단 `아무 key나 눌러 시작하시오`만 표시한다. 일반 키 또는 왼쪽 클릭으로 Stage Select에 진입한다. 키를 누르고 있을 때 발생하는 반복 입력은 화면 전환을 중복 실행하지 않는다. Shift/Ctrl/Alt 같은 보조 키만 누르는 경우에는 진행하지 않는다.

Stage Select에서 Easy/Normal/Hard를 고르고 HAND를 시작한다. CONTINUE는 현재 PC의 저장 기록을 복원한다. 설정, About/Credits, 조작 안내는 이 메뉴에서 열 수 있다. 데이터가 준비되지 않은 부위는 비활성 Coming Soon이다.

## 3D 조작

| 입력 | 동작 |
|---|---|
| 뼈 위 왼쪽 클릭 | 뼈 선택·강조 |
| Piece Index 클릭 | 작은/겹친 뼈를 ID로 선택 |
| 뼈 위 왼쪽 드래그 | 현재 카메라 방향을 기준으로 이동 |
| 오른쪽 드래그 | 카메라 궤도 회전 |
| 가운데 드래그 | 카메라 Pan |
| 마우스 휠 | 확대·축소 |
| 시점 초기화 | 기본 카메라 복원 |
| X / Y / Z | 선택한 뼈를 해당 축으로 +5° 회전 |
| Shift + X / Y / Z | 해당 축으로 −5° 회전 |
| Q / E | 선택한 뼈 Z축 음/양 방향 회전 |
| 회전 패널 −15° / +15° | 해당 축으로 표시된 각도만큼 회전 |
| 방향키 | X/Y 평면에서 0.1 이동 |
| Shift + 방향키 | X/Y 평면에서 0.025 미세 이동 |
| Page Up / Page Down | 깊이 Z 방향 이동 |
| Shift + Page Up / Page Down | 깊이 미세 이동 |
| Enter / Space | 현재 pose의 배치 정답 확인 |
| G | GUIDE ON/OFF |
| Escape | 일시정지/재개, 또는 안내·설정 화면 돌아가기 |

드래그 중에는 카메라 orbit/pan/zoom을 잠근다. 뼈를 잡은 지점의 화면상 offset을 유지하므로 카메라를 돌린 뒤에도 이동이 갑자기 튀지 않게 처리한다. 배치가 끝난 뼈는 선택·학습할 수 있지만 pose는 고정된다. 입력창에 글을 쓰는 동안 회전·이동·G 단축키는 게임 조작으로 처리하지 않는다. 이름 입력창의 Enter는 명칭 Check다.

## 조립과 가이드

GUIDE ON은 미배치 뼈의 목표에 반투명 골격을 보여 준다. GUIDE OFF는 해당 노드들을 실제로 숨기며 정답 윤곽선도 남기지 않는다. 이미 조립한 실제 뼈와 목표 판정 데이터는 유지된다. 가이드 opacity는 켜져 있을 때만 조절할 수 있다. 설정은 난이도와 독립적으로 저장·복원된다.

Easy는 뼈별 snapDistance 안에 놓으면 회전을 보정한다. Normal의 거리는 snapDistance × .75, 회전 오차는 .35 rad 이하이다. Hard는 거리 × .5, 회전 .16 rad 이하이다. 잘못된 위치에 놓으면 고정하지 않는다. 올바른 위치에서는 부드럽게 정답 pose로 정렬하고 고정한다.

## 이름 학습

선택한 뼈의 영어 해부학 이름을 입력한다. `Save note`는 정답 여부와 관계없이 메모를 저장하고 `Check`는 공식 명칭/등록된 별칭만 확인한다. 대소문자와 앞뒤/중복 공백은 무시한다. 이름을 틀린 값으로 수정하면 기존 검증 상태가 해제된다.

힌트는 서로 다른 뼈 5개까지 영어·한국어 이름을 공개한다. 같은 뼈의 힌트 재열람은 추가 차감하지 않으며 입력 메모를 덮어쓰거나 이름 정답으로 자동 처리하지 않는다. 조립 수와 이름 확인 수는 별개다. 이름 확인을 모두 마치지 않아도 27개를 배치하면 조립 결과 화면으로 이동한다.

## 저장·재시작·완료

게임은 현재 PC의 Godot user:// 경로에 pose·배치·명칭·힌트·시간과 일반 설정을 저장한다. 메뉴 이동 또는 종료 시에도 저장한다. 브라우저 버전의 저장과 공유하지 않는다. Pause에서는 시간과 조각 조작을 멈춘다.

Restart/Replay는 현재 HAND의 조립·메모·검증·힌트·시간을 초기화하며 GUIDE, opacity, 모션 감소 설정은 유지한다. 완료 화면에서는 결과를 확인하고, 오른쪽 드래그/휠/Pan으로 완성된 손을 관찰하거나 Replay/Stage Select로 이동한다.
